# 导航模块架构（v3，2026-11-11）

## 导航链路

1. Pilot 主进程识别导航意图，通过 `NavigationClient` 和 AIDL 调用 `NavigationService`。
2. `LocationProvider` 同时启动高德定位和 Android `LocationManager`，系统定位作为高德定位的兜底。
3. 目的地解析优先使用 Web POI API，Web 不可用时再使用 SDK POI 搜索，并应用距离安全阀。
4. 路线优先交给 `AmapNaviEngine` 规划并启动高德 GPS 导航；SDK 缺少 Key、算路失败或熔断时使用 `WebRoutePlanner` 和 `RouteGuide`。
5. SDK 导航语音文本与 Web 路线引导都通过 AIDL 回到主进程，进入 Pilot 统一 TTS 队列。

## 当前 SDK 集成范围

项目的一键 SDK 包含定位 11.3.101、地图 11.3.100、导航 11.3.100、搜索 9.8.1。应用已接入地图导航视图、驾车路线规划、GPS 实时导航、地图路况条、自动跟车缩放、自动日夜模式、定位、POI 搜索和导航语音文本回调。

`NavActivity` 使用高德内置导航 UI。`AmapNaviEngine` 关闭高德内置语音，导航文本交 Pilot TTS 播报。车道、路口放大图、摄像头和交通设施等 SDK 事件目前记录摘要日志，用于确认运行时是否收到回调，尚未全部接入 Pilot 自绘 UI 或播报策略。

SDK 多路线模式已开启；导航界面新增路线按钮，可查看 SDK 返回的候选路线并切换主路线。路线策略通过 SDK 官方转换器应用“躲避拥堵”、最短距离和高速优先偏好。货车、摩托车、步行/骑行、模拟导航和平行路提示 UI 尚未接入产品流程。不能把依赖已打包视为所有功能已启用。

## Key 诊断、算路超时和回退

`NavKeys.check(context)` 只记录 Android SDK Key 与 Web Key 是否注入，不输出密钥内容。注入状态不代表高德服务端已验证通过；以算路回调错误码为准。常见配置类错误包括 `13`（Key 无效）和 `22`（安全码校验失败）。

SDK 单次算路等待上限为 8 秒。缺少 SDK Key 时直接使用 Web 路线；错误码 13/22 后熔断 30 分钟，其他错误或超时后熔断 60 秒。熔断期间新请求直接走 Web，成功的 SDK 算路会清除熔断状态。熔断只在当前导航进程生命周期内生效。

## 距离安全阀

Web POI 搜索优先使用当前位置城市作为偏置；候选点与当前位置距离超过 50 km 时过滤，避免同名地点导致跨城误导航。Web POI 失败时才尝试 SDK POI 搜索。
